# 검색 평가셋 (E0)

상품 검색 회귀 테스트(F8)용 데이터다. 상품과 정답은 모두 합성이며 운영 데이터가 아니다.

| 파일 | 내용 |
|---|---|
| `seed.sql` | 상품 300개, 옵션 554개, 이미지 300개. `id`를 직접 지정하므로 빈 스키마(Testcontainers)에만 넣는다. 검색 행(`product_search`)은 넣지 않는다. 테스트가 백필로 채운다 |
| `queries.csv` | 검색어 665개. `type`은 clean 192, spacing 153, typo 200, vague 120. `relevant_ids`는 `\|`로 구분한 정답 상품 id다 |

## 출처

탐색 실험 E0에서 만들었다. 시드는 생성 스크립트가, 정답은 의도 카드(`intents.csv`)와 규칙으로 계산한 값이다. 생성 스크립트와 원본은 저장소 밖에 있어, 이 파일들을 직접 고치지 않고 통째로 바꾼다.

## 주의

- 점수 분포는 FULLTEXT 통계(IDF)에 따라 달라진다. 하한 검사는 이 시드 300개 기준으로 정한 값이다.
- 상품 수가 다른 데이터(예: 5,000개)에서 잰 recall과 직접 비교하지 않는다.
