# 분류 기준 변경 기록

`criteria.json`의 버전마다 무엇을 왜 바꿨는지 적는다. 평가용 정답을 매기기 시작한 뒤에는 기준을 바꾸지 않는다.

## v0.2 (2026-11-03)

조정용 100개에 사람 정답(1명)을 매긴 뒤, 같은 리뷰를 Fable(Claude 계열)과 Astra(OpenAI 계열)에 v0.1 질문지로 돌려 사람 답과 다른 칸 67개를 봤다(`dataset/probe-*.ts`). 정답이나 일치도를 정하려고 모델을 쓴 것이 아니라, 명세가 애매한 곳을 찾으려고 썼다. 회사가 다른 두 모델이 함께 다르게 고른 칸을 명세가 애매하다는 신호로 봤다.

아래 결정은 모두 그 결과를 보고 사용자가 골랐다. 이유 칸은 선택할 때 제시된 근거다.

| 항목 | 결정 | 이유 | 근거 리뷰 (사람 / Fable / Astra) |
|---|---|---|---|
| 신선도와 상품 상태 | 변질(무름·곰팡이·시듦·쉰내·즙 흐름)은 신선도만, 물리적 손상(멍·찍힘·터짐·깨짐)은 상품 상태만. 둘 다 쓰여 있으면 둘 다 | 판매자 조치가 다르다(변질은 보관·출고 속도, 손상은 선별·완충). 함께 매기면 같은 불만이 두 번 집계된다. v0.1의 경계 판정("물러졌어요"는 신선도, "멍"은 상품 상태)과도 맞다 | 상품 상태 다른 칸 24개 중 21개를 두 모델이 함께 다르게 골랐다. 사람 답은 변질에 상품 상태를 함께 매겼고, 순서에 따라 기준이 두 번 바뀌었다 |
| 결론 없는 리뷰의 전체 감성 | 상품 자체(맛·신선도·상태)를 배송·포장·응대보다 무겁게 본다. 상품 자체에 좋은 말과 나쁜 말이 함께 있을 때만 혼합 | v0.1에서 미정으로 남긴 "맛 최고인데 배송 늦음"의 전체 감성을 정한다. 사람 답이 이 방향으로 일관됐다 | R0066 배송 좋음·맛 밍밍 (n / m / m), R0064 (n / n / m), R0081 (o / n / m) |
| 향 | 맛에 포함 (맛의 진하기도) | 과일·꿀·청 리뷰에 자주 나오고, 빼면 어느 항목에도 잡히지 않는다 | R0063 밤꿀 향 |
| 배송 기사 응대 | 배송에 포함 | 판매자가 택배사를 바꾸는 판단에 쓸 수 있다 | v0.1 초안에서 넣은 규칙을 유지 |
| 잘 익음과 무름 | 불만 표현이 있을 때만 신선도 부정, 없으면 중립 | 품종마다 알맞게 익은 정도가 달라 짐작하지 않는다 | R0079 백도 물렁물렁 (? / n / n) |
| 평가를 미룬 리뷰 | 전체 중립 | 언급은 했지만 평가가 없어 중립 정의("좋다·나쁘다는 평가가 없다")에 맞고, 모델 선택지에 있어 채점할 수 있다 | R0040 아직 안 먹어봄 (? / o / o) |
| 항목 안의 결론 | 전체 감성처럼 결론을 따른다 | 전체와 항목의 규칙을 같게 한다 | R0028 비싸지만 아깝지 않음 (n / m / m) |
| 약한 칭찬·부정문 | 만족 쪽으로 기울면 긍정. 중립은 기울기가 없는 표현에만 | "나쁘지 않아요"는 만족 표현으로 읽힌다 | R0047 나쁘지 않네요 (p / o / p) |
| 동봉물·서비스 | 분석 항목 없음, 전체 감성에만 | 포장은 포장재·완충·밀봉·박스 상태만 다룬다. 판매자 응대와 같은 맥락이다 | R0015 손편지 (포장 p / - / -) |
| 사실만 적은 문장 | 중립 | "짐작하지 않는다"는 원칙과 맞다 | R0091 배송 3일 (? / o / o), R0063 꿀 색 (p / o / o) |

정리한 문구 (규칙 변경 없음):
- 전체 감성 선택지 설명에 결론 규칙을 넣었다. 안내문에만 있으면 "불만이 있지만 재구매" 리뷰에 긍정·부정 설명이 둘 다 맞아 보인다. 공개된 Jev 약점 가운데 지시와 선택지 설명이 어긋날 때의 혼동이 있다.
- 지시문에서 "별점은 보지 말고"를 뺐다. 모델 입력에 별점이 없다.
- 상품 상태 안내문에 "변질은 상품 상태가 아니다", 신선도 안내문에 "물리적 손상은 신선도가 아니다"를 명시했다. 사람도 이 경계를 가장 많이 섞었다.

조정용 사람 정답은 v0.1 기준으로 매긴 그대로 둔다(R0011 가격 `-`, R0039 상품 상태 n만 고침). 조정용은 점수를 매기는 세트가 아니다.
